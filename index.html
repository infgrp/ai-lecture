첨부는 현재 문맥에 자료를 제공할 뿐, 가중치를 바꾸지 않는다.

X

2. "같은 대화 안에서는 앞서 준 지시를 참고할 수 있다."

같은 문맥 창 안의 내용은 다음 토큰 선택의 조건으로 쓰인다.

O

3. "오래 대화하면 기본 모델의 지식이 자동으로 영구 수정된다."

대화 길이는 문맥을 늘릴 뿐이고, 가중치 수정은 별도의 학습 과정이다.

대개 X

  • 다른 프로그램이 파일을 잠갔는지 확인
  • 실습 폴더에 쓰기 권한이 있는지 확인
도구 기능
  • 서버가 쓰기 도구를 제공하는지 확인
  • 다른 이름으로 저장 기능 확인
  • 원본이 아닌 복사본으로 재시도
부록 D — HWP 서식이 깨질 때
  1. 자유 편집 대신 자리표시자 교체 방식으로 단순화한다.
  2. 복잡한 표 삽입을 중단하고 기존 표의 셀만 채운다.
  3. 서버가 더 안정적으로 지원하는 HWP/HWPX 형식을 사용한다.
  4. 결과를 저장한 뒤 한글 프로그램에서 직접 열어 확인한다.
부록 E — 보안과 책임의 최소 원칙

  • MCP 접근 폴더를 실습 폴더로 제한
  • 삭제·전송·업로드 자동 승인 금지
